Esta página presenta el proyecto. El programa se ejecuta en la consola de Java, no en el navegador.

Qué hace el programa

Muestra un menú y repite las opciones hasta que la persona elige salir. Cada opción trabaja sobre la tabla Alumnos con consultas preparadas (PreparedStatement).

Ingresar nuevo

INSERT

Pide el nombre y el correo y guarda el alumno.

Todos los alumnos

SELECT

Lista el ID, el nombre y el correo de cada alumno.

Actualizar registro

UPDATE

Cambia el nombre, el correo o ambos. Si se deja vacío, conserva el valor actual.

Eliminar

DELETE

Borra un alumno a partir de su ID.

Base de datos

El programa usa la base AvanzadaII en SQL Server, con esta tabla:

CREATE TABLE Alumnos (
    id     INT IDENTITY(1,1) PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    correo VARCHAR(150) NOT NULL
);

Cómo ejecutarlo

  1. Ejecuta script_alumnos.sql en SQL Server.
  2. Agrega el driver mssql-jdbc al proyecto.
  3. Define la contraseña de tu usuario de SQL Server con la variable de entorno DB_PASS o con la opción de la JVM -DDB_PASS=tu_contraseña.
  4. Ejecuta la clase org.example.Hola_Mundo.
